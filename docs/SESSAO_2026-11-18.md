# Sessão 2026-11-18 — Projeto Software Innovations (criação do site institucional)

Projeto: [[project_software_innovations]]

## O que foi feito

- Site institucional completo da Software Innovations (CNPJ 28.481.336/0001-32), construído do
  zero: Next.js 16 (App Router) + TypeScript + Tailwind CSS + React Three Fiber (hero 3D) +
  Vitest/RTL, repo próprio e público `andreprol/software-innovations-site`.
- 6 páginas: Home (hero 3D com fallback WebGL, resumo de serviços, prévia de portfólio, selo de
  confiança LGPD/setor público), Soluções (7 categorias, dev sob medida em destaque), Portfólio
  (14 itens agrupados por categoria), Sobre (missão/valores/10 anos de mercado), Contato
  (formulário com gate de LGPD cliente+servidor, integrado ao Resend), Política de Privacidade.
- SEO completo: metadata por página, sitemap.xml, robots.txt, OG image dinâmica
  (`app/opengraph-image.tsx`, `next/og`).
- Implementado via `superpowers:subagent-driven-development` — 16 tasks do plano, cada uma com
  implementador + revisor fresco, vários fix rounds reais (gate de LGPD, vazamento de erro
  interno no 502, memória WebGL, alegação falsa de "não compartilha com terceiro" na política de
  privacidade). Revisão final de branch inteiro (modelo opus) pegou 1 Crítico + 8 Importantes
  adicionais, todos corrigidos num fix wave só (commits `ff2ad8e`..`20536dc`).
- **Achado mais sério da revisão final**: o card de portfólio "RJ Tecnologia" linkava
  `rjtecnologia.com.br` — site de uma empresa **terceira**, sem relação nenhuma com o André.
  O site real que ele reconstruiu é `rjlogisticaetecnologia.com.br`. Corrigido no commit
  `ff2ad8e`. Erro de verificação da própria sessão (confundiu domínio parecido ao checar URLs
  reais do portfólio via `curl` no início da implementação).
- Mesmo commit (`ff2ad8e`): removidos os links de 3 itens de portfólio por segurança/privacidade
  — Delírio Manager (repo público, mas o sistema de produção tem uma vulnerabilidade real ainda
  sem correção — não fazia sentido apontar holofote pro código dela num site de marketing),
  Integração de Portal com SAP B1 e Ambiente Web de RH (ambos repositórios de sistema interno de
  cliente específico). Os cards continuam no site, só sem link clicável.
- Deploy: domínio `softwareinovations.com.br` (1 N — confirmado real via DNS; o domínio com 2 N,
  igual ao logo/WhatsApp, foi perdido e só recupera em 2027) migrado pra Cloudflare (nameservers
  `raina.ns.cloudflare.com` / `walt.ns.cloudflare.com`, trocados pelo André no registro.br),
  DNS A+CNAME apontando pra Vercel, Cloudflare Email Routing configurado
  (`contato@softwareinovations.com.br` → Gmail do André), domínio Resend novo criado com
  DKIM/SPF via CNAME, API key própria gerada e setada nas env vars de produção da Vercel.
  Deploy ao vivo: https://software-innovations-site.vercel.app (vai responder no domínio
  próprio assim que a propagação do NS terminar, ~2h, sem ação manual).

## Decisões tomadas

- Posicionamento do site: puxar forte pra desenvolvimento de software como oferta principal
  (bate com a atividade econômica principal do CNPJ), demais serviços do CNPJ (fiscal,
  RH/ponto, ERP/SAP B1, infraestrutura, marketing digital/reputação, e-commerce) como grid
  secundário — decisão do André, cliente-alvo imediato é o gabinete de um Deputado Federal em
  Brasília.
  - Portfólio puxado do GitHub real do André (`gh repo list`), cobrindo cada categoria de
    serviço com um projeto real correspondente.
- "10 anos de mercado": instrução direta do André em chat, mesmo o CNPJ datando de 22/08/2017
  (~9 anos). Mantido como está — não é inconsistência de dados, é o texto que ele pediu.
- "Sobre"/"Home" — reposicionada a linguagem de "atendemos setor público" (fato não verificável)
  pra "preparados pra atender" (capacidade) — decisão da sessão, sem confirmação de cliente
  público real existente até o momento.
- E-mail de contato criado só com domínio 1 N (`contato@softwareinovations.com.br`) — bate com o
  domínio realmente disponível, não o do logo/WhatsApp (2 N).
- Stack técnica (Next.js + Tailwind + React Three Fiber + Vercel + Cloudflare + Resend) — escolha
  da sessão, dado que o André só pediu "Cloudflare, Vercel etc." e pediu "bem moderno, efeitos
  3D" — segue o mesmo padrão dos outros sites dele (RJ Tecnologia, Uriverse3D).
- Execução via subagent-driven-development (não nativo) — pedido explícito do André: "se tiver 1%
  de chance de comprometer a qualidade, prefiro subagent, ainda que demore mais".
